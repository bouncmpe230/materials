# CMPE230: Systems Programming – Spring 2025

Welcome to the **CMPE230 Systems Programming** course! To ensure a smooth learning experience, we provide a set of repositories and setup guides to help you prepare your environment and deepen your understanding of core systems programming concepts.


## 📌 Organization Repositories

We have prepared several repositories to guide you through setting up your environment and learning the tools, languages, and workflows essential for this course.

### **Environment Setup**
- **Repository:** [bouncmpe230/environment_setup](https://github.com/bouncmpe230/environment_setup)  
- **Description:** A guide for setting up a Unix-like environment (e.g., Ubuntu, Debian, macOS) with essential tools such as compilers, debuggers, and package managers.

### **Docker Starter Course**
- **Repository:** [bouncmpe230/docker-starter-course](https://github.com/bouncmpe230/docker-starter-course)  
- **Description:** A hands-on introduction to Docker, helping you create reproducible environments for your development work.

### **GitHub Classroom Starter Course**
- **Repository:** [bouncmpe230/github-classroom-starter-course](https://github.com/bouncmpe230/github-classroom-starter-course)  
- **Description:** A guide on how to use GitHub Classroom for coursework submissions and collaboration.

### **GitHub Starter Course**
- **Repository:** [bouncmpe230/github-starter-course](https://github.com/bouncmpe230/github-starter-course)  
- **Description:** A beginner-friendly introduction to Git and GitHub for version control and collaboration.


## 💻 Core Programming Topics

These repositories cover foundational and advanced programming topics relevant to systems-level development in C and C++:

### **Unix Commands**
- **Repository:** [bouncmpe230/unix_commands](https://github.com/bouncmpe230/unix_commands)  
- **Description:** A curated set of essential Unix/Linux commands with usage examples and practical exercises.

### **C Core Concepts**
- **Repository:** [bouncmpe230/c-core-concepts](https://github.com/bouncmpe230/c-core-concepts)  
- **Description:** Covers key C programming concepts including memory, control flow, functions, and pointers.

### **C Advanced Concepts**
- **Repository:** [bouncmpe230/c-advanced-concepts](https://github.com/bouncmpe230/c-advanced-concepts)  
- **Description:** Explores advanced C topics such as dynamic memory management, file I/O, bit manipulation, and data structures.

### **C++ Core Concepts**
- **Repository:** [bouncmpe230/cpp_core_concepts](https://github.com/bouncmpe230/cpp_core_concepts)  
- **Description:** An introduction to C++ syntax, object-oriented programming, templates, and STL.
